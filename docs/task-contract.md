# task contract

weak tasks make strong bridges look weak.

send tasks with these fields every time:

- objective
- cwd
- constraints
- deliverables
- review_gate
- return_format

why this matters

openclaw should be deciding where work goes and how results come back.

claude code should be doing repo work inside a narrow scope.

a task with no scope or return shape turns the session into free-form chat.

that is where trust falls apart.

use these examples

- `examples/tasks/smoke-test.md`
- `examples/tasks/repo-fix.md`
- `examples/tasks/repo-fix.envelope.json`
