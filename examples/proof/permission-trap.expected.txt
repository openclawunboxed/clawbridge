expected permission-trap pattern

symptom

common cause
openclaw acpx plugin permissions still behave like a planning session

doc-backed fix path
- set plugins.entries.acpx.config.permissionMode to approve-all for full repo work
- or set nonInteractivePermissions to deny for graceful degradation instead of hard failure
- restart the gateway
- rerun the smoke test and then rerun the task
