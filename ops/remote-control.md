# remote control

official remote control is the cleanest human-to-agent continuation path if you want to keep steering one running local claude code session from another device.

basic start:

    claude remote-control

or:

    claude --remote-control

why it matters:
- the session stays on your machine
- browser and mobile can attach
- your local tools and mcp servers stay available

watch out:
- the terminal must stay open
- requires claude.ai login
- api keys are not supported for remote control
