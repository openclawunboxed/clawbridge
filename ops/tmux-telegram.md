# tmux plus telegram

short answer:

good ops layer

bad core transport

why people still use it:
- phone-first monitoring
- resume from anywhere
- inline approvals in community tools
- tmux scrollback and reattach

why it should not be the center here:
- terminal scraping is fragile
- ansi output is messy
- state is inferred, not native
- agent-to-agent work has a cleaner protocol now

best use here:
- run a visible local claude code session in tmux
- monitor it from your phone if you prefer
- keep acp as the real transport between openclaw and claude
